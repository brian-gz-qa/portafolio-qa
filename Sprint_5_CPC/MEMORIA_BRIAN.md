## 🤖 CÓMO INTERACTUAR CON EL FEED (script probado y funcionando)

**Comentar en una publicación:** `li_comentar_feed.py` (usar con scroll previo de 3 pasadas para cargar el feed)
1. Scroll suave: 3× `mouse.wheel(0,600)` con esperas 2-3s
2. Buscar botón `aria-label="Comentar"` visible → clic JS (más estable que mouse)
3. Esperar 5-7s → editor `.ProseMirror` (placeholder "Editor de texto para crear comentarios")
4. Clic en el editor → escribir por palabras con delay 30-70ms
5. Botón para PUBLICAR = botón con texto exacto **"Comentar"** cerca del editor (¡NO "Publicar"!)
   - Buscar el botón "Comentar" más cercano al editor (dist < 200px) y hacer clic
6. Verificar: el texto del comentario aparece en `document.body.innerText`

**Dar Me gusta:** botón `aria-label="Estado del botón de reacción"`

**Enviar mensaje a conexión:** `li_mensaje_humano.py` — usar URL de compose de la página de conexiones (`/messaging/compose/?profileUrn=...`), editor `.msg-form__contenteditable`, botón "Enviar"

**NOTAS:**
- El feed es DINÁMICO: cada carga muestra publicaciones distintas → siempre hacer scroll antes de buscar
- Los botones "Comentar" con número (ej. aria="Comentar" + contador) son el contador, NO el de publicar
- El de publicar tiene texto exacto "Comentar" y está a la derecha del editor
- Pausas SIEMPRE humanas: 5-7s tras clics, 2-3s entre escritura
